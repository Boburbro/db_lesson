# Database Lessons

This repository contains SQL homework assignments completed while learning PostgreSQL and relational databases.

## First Homework

In the first homework, we practiced basic SQL queries and data filtering:

* `SELECT`
* `WHERE`
* `ORDER BY`
* Aggregate functions:

  * `MIN`
  * `MAX`
  * `COUNT`
* Other basic SQL query operations

File: [first_homework.sql](first_homework.sql)

## Second Homework

In the second homework, we learned how to combine data from multiple tables using SQL `JOIN` operations.

Topics covered:

* `INNER JOIN`
* Joining related tables
* Retrieving data from multiple tables
* Working with relationships between tables

File: [second_homework.sql](second_homework.sql)
